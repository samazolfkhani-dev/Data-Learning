1. String Formatting: The Big Picture

String formatting means inserting values into text and controlling how those values appear.

Suppose you have a user's name and score. You want to produce a readable sentence using both values.

name = "Sara"
score = 92

message = "Sara scored 92 points."

Hard-coding values is inflexible. String formatting lets Python insert variables into a string dynamically.

name = "Sara"
score = 92

message = f"{name} scored {score} points."
print(message)
Key idea: f-strings and str.format() both build strings from text and values. They do not change the original variables.

2. F-Strings

An f-string is a string literal prefixed with f or F. Expressions inside curly braces { } are evaluated and their results are inserted into the string.

2.1 Basic syntax

name = "Alex"
age = 21

print(f"My name is {name} and I am {age} years old.")

Output:

My name is Alex and I am 21 years old.

2.2 Expressions inside braces

You can place expressions—not just variable names—inside the braces.

a = 12
b = 5

print(f"Total: {a + b}")
print(f"Product: {a * b}")
print(f"Next year: {2026 + 1}")
Remember: the expression is evaluated when the f-string is created. The resulting string is an ordinary string; it does not update later if a variable changes.

2.3 Calling functions and methods

name = "  python  "

print(f"Clean name: {name.strip()}")
print(f"Uppercase: {name.upper()}")
print(f"Length: {len(name)}")

2.4 Formatting decimal numbers

Use a format specification after a colon: {value:format_spec}.

FormatMeaningExample result
{price:.2f}Two digits after the decimal point19.50
{ratio:.1%}Percentage with one decimal place87.5%
{number:,}Thousands separator1,250,000
{value:08d}Integer padded to width 8 with zeroes00000042
price = 19.5
ratio = 0.875
population = 1250000
code = 42

print(f"Price: ${price:.2f}")
print(f"Success rate: {ratio:.1%}")
print(f"Population: {population:,}")
print(f"Code: {code:08d}")

2.5 Alignment and width

Width reserves a minimum number of character positions. Alignment controls where the value appears inside that space.

SpecifierMeaning
{text:<10}Left-align in a width of 10
{text:>10}Right-align in a width of 10
{text:^10}Center in a width of 10
{number:*>8}Right-align and fill with *
item = "Book"
print(f"|{item:<10}|")
print(f"|{item:>10}|")
print(f"|{item:^10}|")
print(f"{42:*>8}")

2.6 Debugging with =

In modern Python, {expression=} prints the expression text and its value. It is handy while debugging.

total = 17 * 3
print(f"{total=}")       # total=51
print(f"{17 * 3=}")      # 17 * 3=51

2.7 Literal curly braces

To display actual braces, double them: {{ and }}.

name = "Mina"
print(f"{{Hello, {name}}}")  # {Hello, Mina}
Common trap: this is invalid: f"Hello, {name". Every replacement field needs a matching closing brace.

3. The str.format() Method

str.format() is another way to insert values into a string. The string contains replacement fields, and .format() supplies their values.

3.1 Automatic positional fields

name = "Alex"
age = 21

message = "My name is {} and I am {}.".format(name, age)
print(message)

The first {} receives the first argument; the second receives the second argument.

3.2 Numbered positional fields

message = "{1} is {0} years old.".format(21, "Alex")
print(message)  # Alex is 21 years old.

Indexes start at zero. You can also reuse an index:

text = "{0}, {0}, and {1}".format("red", "blue")
print(text)  # red, red, and blue

3.3 Named fields

message = "Name: {name}, Score: {score}".format(
    name="Sara",
    score=95
)
print(message)

3.4 Format specifications also work here

price = 19.5
print("Price: ${:.2f}".format(price))

name = "Python"
print("|{:<12}|".format(name))
print("|{:^12}|".format(name))

3.5 Accessing attributes and items

user = {"name": "Nina", "score": 88}

print("Name: {0[name]}".format(user))
print("Score: {0[score]}".format(user))
When is format() useful? It is still common in older Python code, reusable templates, and situations where the template string is stored separately. For most new everyday Python code, f-strings are usually clearer.

5. Conditional Statements

Conditions allow a program to make decisions. Python executes a block only when its condition evaluates to True.

5.1 if

temperature = 30

if temperature > 25:
    print("It is warm.")

Python checks the condition. If it is true, the indented block runs. If it is false, Python skips that block.

5.2 if-else

age = 17

if age >= 18:
    print("Access granted.")
else:
    print("Access denied.")

Exactly one of these two branches runs.

5.3 if-elif-else

Use elif when there are multiple possible conditions. Python checks them from top to bottom and executes the first matching branch.

score = 84

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"Grade: {grade}")
Order matters. If you put score >= 60 first, a score of 95 will match it and later branches will never be checked. Put more specific or higher-threshold conditions first.

5.5 Chained comparisons

Python allows readable mathematical comparisons:

age = 24

if 18 <= age < 65:
    print("Working-age range")

This is equivalent to checking both age >= 18 and age < 65.

5.6 Conditional expressions (ternary expressions)

For a simple choice between two values, use this compact expression:

age = 20
status = "Adult" if age >= 18 else "Minor"
print(status)

Do not use nested conditional expressions when they make the code difficult to read.

6. Logical Operators & Truthiness

6.1 and, or, not

OperatorMeaningResult
andTrue only if both operands are truthyTrue and False → False
orTrue if at least one operand is truthyTrue or False → True
notReverses truth valuenot True → False
age = 22
has_id = True

if age >= 18 and has_id:
    print("You may enter.")

is_weekend = True
is_holiday = False

if is_weekend or is_holiday:
    print("No regular work today.")

6.2 Short-circuit evaluation

Python may stop evaluating a logical expression as soon as its final result is known.

username = ""

if username and len(username) >= 5:
    print("Valid username")
else:
    print("Username is empty or too short")

Because an empty string is false, Python does not need to evaluate the second part of the and expression.

6.3 Truthy and falsy values

Conditions do not always need an explicit comparison. Python treats some values as false in Boolean contexts.

Common falsy values

False, None, 0, 0.0, "", [], {}, (), set()

Common truthy values

True, non-zero numbers, non-empty strings, non-empty lists, non-empty dictionaries, and most objects
items = []

if items:
    print("There are items.")
else:
    print("The list is empty.")
Good Python style: write if items: instead of if len(items) > 0: when you only need to check whether a collection is non-empty.

6.4 Membership operators

in checks whether a value exists in a collection or substring.

allowed_roles = ["admin", "editor"]

if "admin" in allowed_roles:
    print("Administrator access is available.")

if "py" in "python":
    print("Substring found.")

7. Loops

A loop repeats a block of code. Python has two main loop statements: for and while.

7.1 for loop

A for loop iterates over the items of an iterable, such as a list, tuple, string, dictionary, set, or range.

languages = ["Python", "C", "Java"]

for language in languages:
    print(language)

On each iteration, the loop variable receives the next item.

7.2 Iterating over a string

word = "CODE"

for character in word:
    print(character)

7.3 range()

range() generates a sequence of integers. The stop value is excluded.

ExpressionGenerated numbers
range(5)0, 1, 2, 3, 4
range(2, 6)2, 3, 4, 5
range(1, 10, 2)1, 3, 5, 7, 9
range(5, 0, -1)5, 4, 3, 2, 1
# start = 1, stop = 6 (excluded), step = 1
for number in range(1, 6):
    print(number)
Off-by-one rule: range(start, stop) includes start but excludes stop. This is one of the most common sources of loop mistakes.

7.4 while loop

A while loop repeats as long as its condition remains true.

count = 1

while count <= 5:
    print(count)
    count += 1

Execution flow:

  1. Check the condition.
  2. If it is true, execute the loop body.
  3. Update relevant variables.
  4. Return to the condition check.
  5. Stop when the condition becomes false.
Infinite loop warning: if the condition never becomes false, the loop may run forever. Make sure the loop has a valid stopping condition or an intentional exit.

7.5 for vs while

forwhile
Best when iterating over a sequence or a known rangeBest when repetition depends on a condition
Gets the next item automaticallyYou often update state manually
Common for lists, strings, files, and rangesCommon for input validation and condition-controlled repetition

7.6 enumerate()

Use enumerate() when you need both an item's index and its value.

names = ["Ali", "Sara", "Nima"]

for index, name in enumerate(names):
    print(index, name)

# Start counting from 1:
for index, name in enumerate(names, start=1):
    print(f"{index}. {name}")

7.7 Iterating over dictionaries

student = {"name": "Sara", "score": 94}

for key in student:
    print(key)                 # keys

for value in student.values():
    print(value)               # values

for key, value in student.items():
    print(f"{key}: {value}")  # key-value pairs

8. break, continue, and pass

StatementWhat it does
breakImmediately exits the nearest enclosing loop.
continueSkips the rest of the current iteration and moves to the next one.
passDoes nothing; it is a placeholder where Python syntax requires a statement.

8.1 break

for number in range(1, 10):
    if number == 5:
        break
    print(number)

# Output: 1 2 3 4

8.2 continue

for number in range(1, 6):
    if number == 3:
        continue
    print(number)

# Output: 1 2 4 5

8.3 pass

for number in range(3):
    if number == 1:
        pass  # TODO: implement this case later
    print(number)
Do not confuse them: break exits the loop; continue skips one iteration; pass simply does nothing.

9. Nested Loops

A nested loop is a loop inside another loop. For every iteration of the outer loop, the inner loop completes all of its iterations (unless control flow interrupts it).

for row in range(1, 4):
    for column in range(1, 3):
        print(f"row={row}, column={column}")

The inner loop runs 2 times for each of the 3 outer iterations: 3 × 2 = 6 total executions of the inner body.

Example: multiplication table

for number in range(1, 4):
    for multiplier in range(1, 4):
        print(f"{number} x {multiplier} = {number * multiplier}")
    print("---")
Performance intuition: if an outer loop runs n times and an inner loop runs m times per outer iteration, the inner body runs n × m times. Nested loops are useful, but large iteration counts can become expensive.

10. Choosing the Right Tool

Formatting

Use an f-string

When you want to insert variables or expressions into a string clearly.

print(f"Total: {a + b}")
Formatting

Use format()

When working with an existing template or reading older code.

"Total: {}".format(total)
Decision

Use if / elif / else

When the program must choose between different paths.

if score >= 50:
    result = "Pass"
else:
    result = "Fail"
Repetition

Use for

When processing each item in an iterable or repeating a known number of times.

for item in items:
    print(item)
Repetition

Use while

When repetition should continue until a condition changes.

while not ready:
    check_status()
Flow control

Use break / continue

When you need to exit a loop early or skip the current iteration.

if invalid:
    continue

Loop-variable caution

# Risky: modifying a list while iterating over it
numbers = [1, 2, 3, 4, 5]

# Better: build a filtered list
evens = [number for number in numbers if number % 2 == 0]

For basic learning, avoid changing the size of a list while looping over that same list. It can cause elements to be skipped or produce confusing behavior.

12. Practice Exercises

Try to solve these without looking up the answers immediately. Write and run your code, then test edge cases.

Exercise 1 — Formatting basics Easy

Create variables product, price, and quantity. Print a sentence using an f-string that includes the total cost. Display the price with two decimal places.

Exercise 2 — Format method Easy

Use str.format() to produce: "Student: Sara | Score: 95". First use positional fields, then rewrite it using named fields.

Exercise 3 — Grade calculator Medium

Ask the user for a score from 0 to 100. Print A for 90–100, B for 80–89, C for 70–79, D for 60–69, and F for below 60. Reject values outside the valid range.

Exercise 4 — Even numbers Medium

Use a for loop and range() to print all even numbers from 2 through 30. Do not hard-code the numbers.

Exercise 5 — Input validation Medium

Keep asking the user to enter a positive integer until they enter a valid positive value. Use a while loop. (You may assume the input is numeric for this exercise.)

Exercise 6 — Find the first match Medium

Given numbers = [4, 9, 12, 7, 18, 5], loop through the list. Print the first number greater than 10 and stop the loop immediately.

Exercise 7 — Skip multiples Medium

Print numbers from 1 to 25, but skip multiples of 3. Use continue.

Exercise 8 — Nested loop pattern Challenge

Use nested loops to print this pattern. Do not use a pre-written multi-line string:

*
**
***
****
*****

Exercise 9 — Mini transaction report Challenge

Given transactions = [120.5, -30, 75, -10.25, 200], calculate the total balance change, count positive and negative transactions separately, and print a neatly formatted report using f-strings. Display money to two decimal places.

Exercise 10 — Number guessing logic Challenge

Set a secret number in a variable. Let the user guess until they are correct. After each wrong guess, print whether the guess is too high or too low. Count and display the number of attempts.

Suggested learning method: solve each exercise, test at least one edge case, and explain aloud why your code works. Reading code feels easy; producing it from a blank file is the real test.
