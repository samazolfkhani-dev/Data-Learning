۱) Function چیست و چرا به آن نیاز داریم؟

تابع (Function) یک بلوک کدِ نام‌گذاری‌شده و قابل‌فراخوانی است که معمولاً یک وظیفه‌ی مشخص را انجام می‌دهد. تابع می‌تواند ورودی بگیرد، پردازش کند و نتیجه برگرداند.

تعریف دقیق: تابع ابزاری برای بسته‌بندی منطق برنامه در یک واحد مستقل است؛ به‌جای تکرار یک الگوریتم، آن را یک‌بار تعریف می‌کنیم و هرجا لازم شد فراخوانی می‌کنیم.
Reusabilityیک منطق را چند بار و در بخش‌های مختلف استفاده می‌کنیم.
Modularityبرنامه را به بخش‌های کوچک‌تر با مسئولیت روشن تقسیم می‌کنیم.
Maintainabilityاصلاح یک رفتار در یک نقطه انجام می‌شود، نه در ده جای مختلف.
Testabilityهر تابع را می‌توان جداگانه آزمایش کرد.

بدون تابع در برابر تابع‌محور

# تکرار منطق
price1 = 120
print(price1 * 1.09)

price2 = 250
print(price2 * 1.09)

# بسته‌بندی منطق در تابع
def add_tax(price):
    return price * 1.09

print(add_tax(120))
print(add_tax(250))
قاعده‌ی طراحی: هر تابع بهتر است یک مسئولیت روشن داشته باشد. تابعی که هم فایل می‌خواند، هم داده را پاک‌سازی می‌کند، هم گزارش چاپ می‌کند و هم ایمیل می‌فرستد، احتمالاً بیش از حد مسئولیت گرفته است.

۲) تعریف و فراخوانی تابع

برای تعریف تابع از کلمه‌ی کلیدی def استفاده می‌کنیم. بدنه‌ی تابع با تورفتگی (indentation) مشخص می‌شود.

def function_name(parameters):
    """Optional docstring."""
    statement
    return result
بخشمعنا
defاعلام تعریف یک تابع
function_nameنام تابع؛ بهتر است توصیفی و با snake_case باشد.
parametersنام متغیرهایی که تابع هنگام اجرا ورودی را از طریق آن‌ها دریافت می‌کند.
بدنهدستورهایی که هنگام فراخوانی اجرا می‌شوند.
returnپایان اجرای تابع و تحویل نتیجه به فراخواننده.

مثال پایه

def greet():
    print("Hello, Python!")

greet()  # function call
greet()  # same function, another call
نکته‌ی مهم: تعریف تابع به‌تنهایی بدنه‌ی آن را اجرا نمی‌کند. تا وقتی تابع را فراخوانی نکنیم، دستورات داخل آن اجرا نخواهند شد.

نام‌گذاری تابع

  • از نام معنادار استفاده کن: calculate_total() بهتر از ct() است.
  • نام تابع معمولاً فعل یا ترکیب فعل‌محور است: get_user()، validate_email().
  • از نام توابع داخلی مثل sum، list، str و max برای تابع خودت استفاده نکن؛ نام داخلی را سایه می‌اندازی.
  • نام تابع به حروف بزرگ و کوچک حساس است: print_data با Print_Data یکی نیست.

۳) Parameters و Arguments

این دو اصطلاح نزدیک‌اند اما یکی نیستند:

Parameter (پارامتر)متغیری که در تعریف تابع نوشته می‌شود.
Argument (آرگومان)مقدار واقعی‌ای که هنگام فراخوانی به تابع می‌دهیم.
def welcome(name):       # name = parameter
    print(f"Welcome, {name}")

welcome("Sama")          # "Sama" = argument

۳.۱ آرگومان موقعیتی (Positional)

مقدار بر اساس ترتیب پارامترها به آن‌ها نسبت داده می‌شود.

def introduce(name, age):
    print(name, age)

introduce("Sara", 21)  # name='Sara', age=21

ترتیب را اشتباه بدهی، ممکن است برنامه بدون خطا ولی با نتیجه‌ی غلط اجرا شود.

۳.۲ آرگومان کلیدواژه‌ای (Keyword)

با نوشتن نام پارامتر، مقدار را صریحاً به آن وصل می‌کنیم؛ بنابراین ترتیب آرگومان‌ها مهم نیست.

def introduce(name, age):
    print(name, age)

introduce(age=21, name="Sara")

۳.۳ مقدار پیش‌فرض (Default Parameter)

اگر برای پارامتری مقدار پیش‌فرض تعریف کنیم، فراخواننده می‌تواند آن آرگومان را حذف کند.

def greet(name, message="Hello"):
    print(f"{message}, {name}")

greet("Sara")                 # Hello, Sara
greet("Ali", "Good morning")  # Good morning, Ali
قانون ترتیب: پارامترهای بدون مقدار پیش‌فرض باید قبل از پارامترهای دارای مقدار پیش‌فرض بیایند. def f(a=1, b): خطای SyntaxError می‌دهد؛ اما def f(a, b=1): معتبر است.

۳.۴ Keyword-only و Positional-only

با علامت‌های / و * می‌توان تعیین کرد پارامترها چگونه قابل ارسال باشند.

def create_user(user_id, /, name, *, active=True):
    print(user_id, name, active)

create_user(10, "Sara", active=False)
# user_id must be positional
# active must be keyword-only
علامتکاربرد
/پارامترهای قبل از آن فقط موقعیتی‌اند (positional-only).
*پارامترهای بعد از آن فقط کلیدواژه‌ای‌اند (keyword-only)، مگر اینکه در قالب *args باشد.

۳.۵ ترتیب کلی پارامترها

def f(pos_only, /, standard, *args, keyword_only, **kwargs):
    pass

این امضا همه‌ی شکل‌های اصلی پارامتر را کنار هم نشان می‌دهد؛ لازم نیست در توابع معمولی همیشه از همه‌ی آن‌ها استفاده کنی.

۴) return، print و مقدار بازگشتی

این تفاوت، از مهم‌ترین مفاهیم توابع است.

print()return
مقدار را برای انسان در خروجی نمایش می‌دهد.مقدار را از تابع به کد فراخواننده تحویل می‌دهد.
به‌خودی‌خود نتیجه را برای استفاده‌ی بعدی ذخیره نمی‌کند.می‌توان نتیجه را در متغیر ذخیره، مقایسه یا به تابع دیگری ارسال کرد.
تابع print خودش None برمی‌گرداند.اجرای تابع را همان‌جا خاتمه می‌دهد.
def add_print(a, b):
    print(a + b)

def add_return(a, b):
    return a + b

x = add_print(2, 3)   # prints 5; x is None
y = add_return(2, 3)  # y is 5

print(x)              # None
print(y * 10)         # 50

اگر return ننویسیم چه می‌شود؟

پایتون به‌صورت خودکار None برمی‌گرداند. همین اتفاق وقتی رخ می‌دهد که فقط از return بدون مقدار استفاده کنیم.

def do_nothing():
    pass

def stop_early():
    print("Starting")
    return
    print("This line never runs")

print(do_nothing())  # None

بازگرداندن چند مقدار

در پایتون می‌توان چند مقدار را با کاما برگرداند. در واقع یک tuple ساخته می‌شود.

def calculate(a, b):
    return a + b, a - b, a * b

result = calculate(8, 3)
print(result)             # (11, 5, 24)

total, difference, product = calculate(8, 3)
هر دستوری بعد از return در همان مسیر اجرا نمی‌شود. return فقط مقدار نمی‌دهد؛ اجرای تابع را هم تمام می‌کند.

چند return در یک تابع

def classify(number):
    if number > 0:
        return "positive"
    elif number < 0:
        return "negative"
    return "zero"

۵) *args و **kwargs

وقتی تعداد آرگومان‌ها از قبل مشخص نیست، از این دو ابزار استفاده می‌کنیم.

۵.۱ *args — تعداد متغیر آرگومان‌های موقعیتی

آرگومان‌های موقعیتی اضافی داخل یک tuple جمع می‌شوند. نام args قراردادی است؛ ستاره مهم است.

def total(*args):
    print(args)
    return sum(args)

print(total(2, 4, 6))       # 12
print(total(10, 20))        # 30

۵.۲ **kwargs — تعداد متغیر آرگومان‌های کلیدواژه‌ای

آرگومان‌های کلیدواژه‌ای اضافی داخل یک dictionary جمع می‌شوند.

def show_profile(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

show_profile(name="Sara", age=21, city="Zanjan")

۵.۳ ترکیب آن‌ها

def report(title, *scores, status="active", **details):
    print(title)
    print(scores)    # tuple
    print(status)
    print(details)   # dict

report("Python", 18, 20, 17, status="passed", level="basic")

۵.۴ Unpacking با * و **

ستاره‌ها فقط برای تعریف تابع نیستند؛ هنگام فراخوانی هم می‌توانند یک مجموعه را باز کنند.

def add(a, b, c):
    return a + b + c

numbers = [2, 3, 4]
print(add(*numbers))  # equivalent to add(2, 3, 4)

def connect(host, port):
    print(host, port)

config = {"host": "localhost", "port": 5432}
connect(**config)
تفاوت را حفظ کن: در تعریف تابع، *args ورودی‌های اضافی را جمع می‌کند؛ در فراخوانی، *iterable یک iterable را باز می‌کند. برای ** نیز همین منطق با آرگومان‌های کلیدواژه‌ای و mapping برقرار است.

۶) Scope و فضای نام (Namespace)

Scope مشخص می‌کند یک نام (variable/function name) از کدام بخش برنامه قابل دسترسی است. Namespace فضایی است که نام‌ها را به اشیا متصل می‌کند.

۶.۱ Local Scope

نامی که داخل تابع تعریف می‌شود، معمولاً local همان تابع است.

def calculate():
    result = 100  # local variable
    print(result)

calculate()
# print(result)  -> NameError

۶.۲ Global Scope

نامی که در سطح اصلی ماژول تعریف شده، global آن ماژول است و از داخل توابع قابل خواندن است.

tax_rate = 0.09

def final_price(price):
    return price * (1 + tax_rate)

print(final_price(100))

۶.۳ قانون LEGB

هنگام جست‌وجوی یک نام، پایتون این ترتیب را بررسی می‌کند:

L — Localنام‌های محلی تابع فعلی
E — Enclosingفضای تابع بیرونی در توابع تو‌در‌تو
G — Globalفضای سطح ماژول
B — Built-inنام‌های داخلی پایتون مثل len و sum
message = "global"

def outer():
    message = "enclosing"

    def inner():
        message = "local"
        print(message)

    inner()

outer()  # local

اگر نام در Local پیدا نشود، پایتون به Enclosing، سپس Global و در نهایت Built-in می‌رود. اگر هیچ‌جا پیدا نشود، NameError رخ می‌دهد.

۶.۴ Shadowing — سایه انداختن روی نام

name = "Global"

def show():
    name = "Local"
    print(name)

show()          # Local
print(name)     # Global

تعریف نام محلی با همان نام global، مقدار global را تغییر نمی‌دهد؛ فقط هنگام جست‌وجو در آن تابع، نام محلی زودتر پیدا می‌شود.

متغیر local بعد از پایان فراخوانی تابع معمولاً از دسترس مستقیم خارج می‌شود. البته اگر یک closure آن را نگه دارد، ممکن است عمرش ادامه پیدا کند.

۷) دستورهای global و nonlocal

۷.۱ چرا گاهی UnboundLocalError می‌گیریم؟

اگر داخل تابع به نامی مقداردهی کنیم، پایتون آن نام را در همان تابع local در نظر می‌گیرد؛ حتی اگر بیرون تابع متغیر global با همان نام وجود داشته باشد.

count = 10

def increase():
    count = count + 1  # UnboundLocalError

increase()

پایتون در خط بالا می‌بیند که count در تابع مقداردهی شده، پس آن را local تشخیص می‌دهد؛ اما قبل از مقداردهی، تلاش می‌کنیم مقدارش را بخوانیم.

۷.۲ global

با global اعلام می‌کنیم که assignment روی نام global ماژول انجام شود.

count = 10

def increase():
    global count
    count += 1

increase()
print(count)  # 11
استفاده‌ی زیاد از global معمولاً طراحی را شکننده می‌کند؛ وابستگی پنهان می‌سازد و تست‌کردن تابع را سخت‌تر می‌کند. اغلب بهتر است مقدار را ورودی بگیریم و نتیجه را return کنیم.

۷.۳ nonlocal

nonlocal برای تغییر متغیری است که در نزدیک‌ترین تابع بیرونی (Enclosing function) تعریف شده؛ نه global و نه local تابع فعلی.

def outer():
    score = 0

    def inner():
        nonlocal score
        score += 5

    inner()
    return score

print(outer())  # 5
دستوربه کدام نام اشاره می‌کند؟کاربرد
global xنام در سطح ماژولassignment روی متغیر global
nonlocal xنام در تابع بیرونیِ غیر globalassignment روی متغیر enclosing

اگر نام مناسبی برای nonlocal در تابع بیرونی وجود نداشته باشد، پایتون SyntaxError می‌دهد.

۸) توابع تو‌در‌تو و Closure

۸.۱ Nested Function

تابعی که داخل تابع دیگری تعریف شود، nested function نام دارد. معمولاً برای پنهان‌کردن جزئیات پیاده‌سازی یا ساخت رفتارهای قابل‌تنظیم استفاده می‌شود.

def calculate_discount(price):
    def apply_discount():
        return price * 0.8

    return apply_discount()

print(calculate_discount(100))  # 80.0

۸.۲ Closure چیست؟

اگر تابع داخلی به متغیرهای تابع بیرونی وابسته باشد و خود تابع داخلی از تابع بیرونی برگردانده شود، تابع برگشتی می‌تواند آن متغیرها را حتی پس از پایان اجرای تابع بیرونی نگه دارد. به این رفتار closure می‌گوییم.

def multiplier(factor):
    def multiply(number):
        return number * factor
    return multiply

double = multiplier(2)
triple = multiplier(3)

print(double(10))  # 20
print(triple(10))  # 30
تصویر ذهنی: تابع multiply فقط کد نیست؛ به همراه ارجاعی به محیطی که factor در آن تعریف شده، برگردانده می‌شود. برای همین هنوز می‌داند ضریب چند است.

۸.۳ کاربرد Closure

  • ساخت تابع‌های قابل پیکربندی
  • نگهداری state محدود و خصوصی
  • پیاده‌سازی decoratorها
  • ساخت callbackهایی که به تنظیمات اولیه نیاز دارند

۹) Lambda Function

تابع lambda یک تابع کوچک و بی‌نام است که با کلمه‌ی lambda ساخته می‌شود. بدنه‌ی آن فقط یک expression است و نتیجه‌ی همان expression به‌صورت ضمنی برگردانده می‌شود.

square = lambda x: x ** 2
print(square(5))  # 25

add = lambda a, b: a + b
print(add(3, 4))  # 7
deflambda
نام‌گذاری طبیعی و مناسب منطق چندخطیبی‌نام و مناسب expression کوتاه
می‌تواند چند دستور داشته باشد.فقط یک expression دارد.
می‌تواند docstring داشته باشد.ساختار docstring معمول ندارد.

کاربرد رایج همراه sorted و key

students = [
    {"name": "Sara", "score": 18},
    {"name": "Ali", "score": 15},
    {"name": "Mina", "score": 20}
]

ordered = sorted(students, key=lambda student: student["score"])
print(ordered)
اگر lambda آن‌قدر پیچیده شد که برای فهمیدنش باید مکث کنی، احتمالاً یک تابع def با نام خوب انتخاب بهتری است.

۱۰) نکات حرفه‌ای و جزئیات مهم

۱۰.۱ توابع در پایتون First-class Objects هستند

تابع در پایتون یک object است؛ می‌توان آن را در متغیر ذخیره کرد، به تابع دیگری داد، از تابع برگرداند و داخل ساختار داده نگهداری کرد.

def greet(name):
    return f"Hello {name}"

say_hello = greet
print(say_hello("Sara"))

def run_function(func, value):
    return func(value)

print(run_function(greet, "Ali"))

۱۰.۲ Docstring و مستندسازی

رشته‌ای که اولین دستور بدنه‌ی تابع باشد، docstring است. برای توضیح هدف، ورودی‌ها، خروجی و خطاهای احتمالی استفاده می‌شود.

def calculate_area(width, height):
    """Return the area of a rectangle.

    Args:
        width (float): Rectangle width.
        height (float): Rectangle height.

    Returns:
        float: Rectangle area.
    """
    return width * height

print(calculate_area.__doc__)
help(calculate_area)

۱۰.۳ Type Hints / Annotations

Type hint نوع مورد انتظار ورودی و خروجی را مستند می‌کند و به ابزارهای تحلیل کد کمک می‌کند؛ اما به‌طور پیش‌فرض نوع را در زمان اجرا enforce نمی‌کند.

def average(numbers: list[float]) -> float:
    return sum(numbers) / len(numbers)

۱۰.۴ توابع بازگشتی (Recursion)

تابع بازگشتی تابعی است که خودش را فراخوانی می‌کند. باید شرط توقف (base case) داشته باشد؛ وگرنه فراخوانی‌ها ادامه پیدا می‌کنند تا به محدودیت عمق بازگشت برسند.

def factorial(n):
    if n < 0:
        raise ValueError("n must be non-negative")
    if n <= 1:              # base case
        return 1
    return n * factorial(n - 1)

print(factorial(5))  # 120
در پایتون recursion همیشه بهترین انتخاب نیست. برای پیمایش‌های عمیق، حلقه معمولاً امن‌تر است؛ چون محدودیت recursion وجود دارد و پایتون به‌طور پیش‌فرض tail-call optimization انجام نمی‌دهد.

id(obj)شناسه‌ی هویت شیء در طول عمر آنid(greet)
type(obj)نوع شیءtype(greet)
globals()دیکشنری namespace سراسری ماژولglobals().keys()

vars(obj)دیکشنری ویژگی‌های شیء، در صورت پشتیبانیvars(some_object)

۱۰.۶ ویژگی‌های قابل‌بررسی تابع

def greet(name: str = "Guest") -> str:
    """Create a greeting."""
    return f"Hello, {name}"

print(greet.__name__)         # greet
print(greet.__doc__)          # Create a greeting.
print(greet.__defaults__)     # ('Guest',)
print(greet.__annotations__)  # {'name': str, 'return': str}

۱۰.۷ Function در برابر Method

Function به‌طور مستقل تعریف می‌شود. Method تابعی است که به یک کلاس یا نمونه‌ی کلاس وابسته است. متد نمونه معمولاً پارامتر اولی به نام self دارد که نمونه‌ی فعلی را دریافت می‌کند.

def standalone():
    return "I am a function"

class Student:
    def study(self):
        return "I am an instance method"

s = Student()
print(standalone())
print(s.study())

۱۰.۸ Decorator — پیش‌نمایش

Decorator تابعی است که تابع دیگری را می‌گیرد و معمولاً نسخه‌ای با رفتار اضافه‌شده برمی‌گرداند. برای فهم عمیق decoratorها باید closure و first-class functions را خوب بلد باشی.

def announce(func):
    def wrapper():
        print("Starting...")
        result = func()
        print("Finished.")
        return result
    return wrapper

@announce
def task():
    print("Working")

task()

۱۱) دام‌ها و اشتباهات رایج

۱۱.۱ مقدار پیش‌فرض mutable

مقادیر پیش‌فرض فقط یک‌بار، هنگام تعریف تابع ساخته می‌شوند؛ نه در هر فراخوانی. پس استفاده از list یا dict قابل‌تغییر می‌تواند state ناخواسته ایجاد کند.

# Bad
def add_item(item, items=[]):
    items.append(item)
    return items

# Good
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

۱۱.۲ تفاوت تغییر شیء و انتساب مجدد

values = [1, 2]

def modify(items):
    items.append(3)       # mutates the same list

modify(values)
print(values)             # [1, 2, 3]

def reassign(items):
    items = [9, 9]        # local rebinding

reassign(values)
print(values)             # [1, 2, 3]

پایتون از مدل ارسال آرگومان بر پایه‌ی object reference / object sharing استفاده می‌کند: تابع ارجاع به همان شیء را دریافت می‌کند. mutation شیء قابل‌تغییر از بیرون دیده می‌شود؛ اما انتساب مجدد پارامتر، نام بیرونی را عوض نمی‌کند.

۱۱.۳ تفاوت NameError و UnboundLocalError

  • NameError: نام در scopeهای قابل‌جست‌وجو پیدا نشده است.
  • UnboundLocalError: نام local تشخیص داده شده، اما پیش از مقداردهی از آن استفاده شده است؛ زیرکلاس NameError است.

۱۱.۴ فراخوانی تابع را با ارجاع به تابع اشتباه نگیر

def greet():
    print("Hello")

x = greet      # function object
y = greet()    # function call; y gets return value (None)

x()
print(y)

۱۱.۵ نام‌های built-in را بازنویسی نکن

# Avoid this
list = [1, 2, 3]
# Now list(...) no longer refers to built-in list

۱۳) خودآزمایی مفهومی

قبل از باز کردن پاسخ، خودت خروجی را پیش‌بینی کن. هدف حفظ‌کردن نیست؛ باید بتوانی رفتار مفسر را توضیح بدهی.

سؤال ۱ — خروجی چیست؟
def f(x):
    x = x + 2
    return x

a = 5
print(f(a), a)
7 5 — مقدار عددی immutable است؛ انتساب مجدد x نام محلی را تغییر می‌دهد، نه a را.
سؤال ۲ — خروجی چیست؟
def outer():
    x = "A"
    def inner():
        print(x)
    inner()

outer()
A — نام در Local تابع inner نیست، پس در Enclosing پیدا می‌شود.
سؤال ۳ — مشکل کجاست؟
total = 10
def update():
    total += 5
update()
UnboundLocalError — چون assignment باعث می‌شود total در update محلی تشخیص داده شود. برای تغییر global باید global total نوشت؛ طراحی بهتر معمولاً return مقدار جدید است.
سؤال ۴ — خروجی چیست؟
def collect(value, bucket=[]):
    bucket.append(value)
    return bucket

print(collect(1))
print(collect(2))
[1] و سپس [1, 2] — لیست پیش‌فرض فقط یک‌بار ساخته شده و بین فراخوانی‌ها مشترک مانده است.
سؤال ۵ — این تابع چه چیزی برمی‌گرداند؟
def stats(a, b):
    return a + b, a * b

result = stats(3, 4)
print(type(result), result)
نوع tuple و مقدار (7, 12) — چند مقدار جداگانه برنمی‌گردند؛ یک tuple برگردانده می‌شود.
