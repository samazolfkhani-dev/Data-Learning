۱. آشنایی با ساختارهای داده

در پایتون، Data Structure روشی برای ذخیره و سازمان‌دهی داده‌هاست. تا اینجا با List و Tuple آشنا شده‌ای. حالا دو ساختار مهم دیگر را یاد می‌گیریم:

  • Set: مجموعه‌ای از اعضای یکتا؛ برای حذف تکراری‌ها و انجام عملیات ریاضی مجموعه‌ها.
  • Dictionary: مجموعه‌ای از جفت‌های کلید ـ مقدار؛ برای دسترسی به داده از طریق یک کلید معنادار.

۲. Set چیست؟

set مجموعه‌ای از عناصر یکتا و hashable است. تکراری‌ها هنگام ساخت مجموعه حذف می‌شوند.

numbers = {1, 2, 3, 2, 1}
print(numbers)       # {1, 2, 3}  (ترتیب خروجی تضمین‌شده نیست)
print(len(numbers))  # 3

ساخت Set

# روش اول: آکولاد
colors = {"red", "green", "blue"}

# روش دوم: تابع set()
numbers = set([1, 2, 2, 3])
letters = set("banana")  # {'b', 'a', 'n'}

# ساخت مجموعه خالی
empty_set = set()
دام امتحانی: عبارت {} یک دیکشنری خالی می‌سازد، نه Set خالی. برای Set خالی حتماً بنویس set().

چه چیزهایی داخل Set قرار می‌گیرند؟

اعضا باید hashable باشند؛ معمولاً انواع immutable مثل int، str، float و tupleای که تمام اعضایش hashable باشند.

valid = {10, "Python", (1, 2), 3.5}

# خطا: list و dict قابل hash نیستند
# invalid = {[1, 2], {"a": 1}}
Hashable یعنی چه؟ شیئی که در طول عمر خود هشِ ثابت دارد و می‌تواند به‌عنوان عضو Set یا کلید Dictionary استفاده شود. قابل‌تغییر بودن معمولاً با hashable بودن سازگار نیست؛ به همین دلیل List و Dictionary عضو Set نمی‌شوند.

Set ایندکس ندارد

items = {"apple", "banana", "orange"}
# print(items[0])  # TypeError: set از index پشتیبانی نمی‌کند

for item in items:
    print(item)

برای بررسی وجود یک عضو از in استفاده کن:

if "apple" in items:
    print("Found")

۳. عملیات ریاضی روی Set

فرض کن دو مجموعه زیر را داریم:

A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

Union — اجتماع

تمام اعضایی که در A یا B یا هر دو هستند. تکراری‌ها فقط یک‌بار می‌آیند.

print(A | B)
print(A.union(B))
# {1, 2, 3, 4, 5, 6}

Intersection — اشتراک

فقط اعضایی که در هر دو مجموعه وجود دارند.

print(A & B)
print(A.intersection(B))
# {3, 4}

Difference — تفاضل

A - B اعضای موجود در A و غایب در B را برمی‌گرداند. جهت عملیات مهم است.

print(A - B)  # {1, 2}
print(B - A)  # {5, 6}
print(A.difference(B))

Symmetric Difference — تفاضل متقارن

اعضایی که فقط در یکی از دو مجموعه‌اند، نه در هر دو.

print(A ^ B)
print(A.symmetric_difference(B))
# {1, 2, 5, 6}

Subset و Superset

X = {1, 2}
Y = {1, 2, 3}

print(X <= Y)  # True: زیرمجموعه یا برابر
print(X < Y)   # True: زیرمجموعه واقعی
print(Y >= X)  # True: ابرمجموعه یا برابر
print(Y > X)   # True: ابرمجموعه واقعی

print(X.issubset(Y))
print(Y.issuperset(X))

Disjoint — اشتراک تهی

first = {1, 2}
second = {3, 4}
print(first.isdisjoint(second))  # True
کاربرد واقعی: اگر بخواهی بفهمی دو گروه کاربر هیچ عضو مشترکی ندارند، isdisjoint() دقیقاً برای همین کار است.

۴. تمام متدهای Set

متدهای Set را می‌توان به دو گروه تقسیم کرد: متدهایی که خود مجموعه را تغییر می‌دهند و متدهایی که نتیجه جدید یا مقدار منطقی برمی‌گردانند.

متدکاربردنکته
add(x)افزودن یک عضواگر تکراری باشد، تغییری نمی‌کند.
update(iterable)افزودن همه اعضای iterableهر عنصر iterable جداگانه اضافه می‌شود.
remove(x)حذف عضواگر عضو نباشد KeyError می‌دهد.
discard(x)حذف عضواگر عضو نباشد خطا نمی‌دهد.
pop()حذف و برگرداندن یک عضوعضو انتخابی قابل پیش‌بینی نیست؛ Set خالی خطا می‌دهد.
clear()خالی کردن مجموعهخود مجموعه را تغییر می‌دهد.
copy()کپی سطحییک Set جدید می‌سازد.
union(*others)اجتماعSet جدید برمی‌گرداند.
intersection(*others)اشتراکSet جدید برمی‌گرداند.
difference(*others)تفاضلSet جدید برمی‌گرداند.
symmetric_difference(other)تفاضل متقارنSet جدید برمی‌گرداند.
intersection_update(*others)نگه‌داشتن فقط اشتراکخود مجموعه را تغییر می‌دهد.
difference_update(*others)حذف اعضای مجموعه‌های دیگرخود مجموعه را تغییر می‌دهد.
symmetric_difference_update(other)جایگزینی با تفاضل متقارنخود مجموعه را تغییر می‌دهد.
issubset(other)بررسی زیرمجموعه بودنBoolean برمی‌گرداند.
issuperset(other)بررسی ابرمجموعه بودنBoolean برمی‌گرداند.
isdisjoint(other)بررسی نداشتن عضو مشترکBoolean برمی‌گرداند.

add در برابر update

numbers = {1, 2}
numbers.add(3)
print(numbers)  # {1, 2, 3}

numbers.update([4, 5], (6, 7))
print(numbers)  # اعضای 4 تا 7 هم اضافه می‌شوند

letters = set()
letters.add("cat")       # یک عضو به نام "cat"
letters.update("cat")    # حروف c و a و t به‌صورت جداگانه

remove در برابر discard

values = {10, 20, 30}
values.remove(20)   # حذف می‌شود
# values.remove(99) # KeyError

values.discard(99)  # بدون خطا؛ چون 99 وجود ندارد

pop و clear

values = {10, 20, 30}
removed = values.pop()
print(removed)  # یکی از اعضا؛ عضو دقیق تضمین نشده است

values.clear()
print(values)   # set()

نسخه‌های Update

A = {1, 2, 3, 4}
B = {3, 4, 5}

A.intersection_update(B)
print(A)  # {3, 4}

A = {1, 2, 3, 4}
A.difference_update({3, 4})
print(A)  # {1, 2}

A = {1, 2, 3}
A.symmetric_difference_update({3, 4})
print(A)  # {1, 2, 4}
نکته حیاتی: متدهای تغییردهنده مثل add()، update() و clear() معمولاً None برمی‌گردانند. این اشتباه است: result = A.add(5)؛ متغیر result برابر None می‌شود، نه Set جدید.

عملگرها یا متدها؟

عملگرمتد متناظرتفاوت مهم
A | BA.union(B)عملگرها معمولاً operandهای Set می‌خواهند؛ متدها iterableهای مناسب را هم می‌پذیرند.
A & BA.intersection(B)همین تفاوت نوع ورودی
A - BA.difference(B)همین تفاوت نوع ورودی
A ^ BA.symmetric_difference(B)همین تفاوت نوع ورودی

۵. Dictionary چیست؟

دیکشنری داده‌ها را به شکل جفت‌های key: value نگه می‌دارد. به‌جای اینکه با شماره اندیس به داده برسیم، با یک کلید آن را پیدا می‌کنیم.

student = {
    "name": "Sara",
    "age": 21,
    "major": "Computer Engineering"
}

print(student["name"])  # Sara
print(student["age"])   # 21

ساخت Dictionary

# با آکولاد
person = {"name": "Ali", "age": 22}

# با dict()
person2 = dict(name="Ali", age=22)

# از جفت‌های کلید و مقدار
pairs = [("a", 1), ("b", 2)]
letters = dict(pairs)

# دیکشنری خالی
empty_dict = {}

قوانین Key و Value

  • کلیدها باید یکتا باشند. اگر یک کلید را چند بار بنویسی، مقدار آخر باقی می‌ماند.
  • کلید باید hashable باشد؛ مثلاً رشته، عدد یا tuple مناسب.
  • مقدار می‌تواند هر نوع داده‌ای باشد: عدد، رشته، List، Set، Dictionary یا حتی تابع.
  • کلید و مقدار لازم نیست هم‌نوع باشند.
data = {
    "name": "Mina",
    10: "ten",
    (1, 2): "coordinate",
    "scores": [18, 19, 20],
    "profile": {"city": "Zanjan"}
}

duplicate = {"x": 1, "x": 99}
print(duplicate)  # {'x': 99}
نکته: این کد خطا می‌دهد چون List قابل hash نیست: {[1, 2]: "value"}. اما این کاملاً مجاز است: {"scores": [18, 19]}؛ چون List در اینجا value است، نه key.

دسترسی به مقدار

student = {"name": "Sara", "age": 21}

print(student["name"])  # Sara
# print(student["grade"])  # KeyError

print(student.get("grade"))       # None
print(student.get("grade", 0))    # 0

dict[key] در صورت نبود کلید خطا می‌دهد؛ get() در صورت نبود کلید مقدار پیش‌فرض یا None برمی‌گرداند.

افزودن و تغییر مقدار

student = {"name": "Sara", "age": 21}

student["age"] = 22           # تغییر مقدار موجود
student["city"] = "Zanjan"    # افزودن کلید جدید

print(student)

حذف عضو

student = {"name": "Sara", "age": 21}

del student["age"]            # حذف با کلید
age = student.pop("age", 0)   # حذف و برگرداندن مقدار؛ پیش‌فرض اختیاری
last_item = student.popitem() # حذف و برگرداندن آخرین جفت درج‌شده
student.clear()               # خالی کردن کل دیکشنری

دقت کن که در مثال بالا بعد از del، کلید age دیگر وجود ندارد؛ بنابراین اجرای بعدی pop("age") بدون default خطا می‌دهد. مثال‌ها را جداگانه اجرا کن یا ترتیبشان را تغییر بده.

پیمایش دیکشنری با for

scores = {"Sara": 18, "Ali": 16, "Mina": 20}

# پیمایش کلیدها (رفتار پیش‌فرض)
for name in scores:
    print(name)

# پیمایش مقادیر
for score in scores.values():
    print(score)

# پیمایش کلید و مقدار
for name, score in scores.items():
    print(name, score)
قاعده طلایی: وقتی هم کلید و هم مقدار را لازم داری، از items() استفاده کن و دو متغیر در حلقه بگیر: for key, value in my_dict.items().

۶. تمام متدهای اصلی Dictionary

متدکاربردخروجی / نکته
get(key, default=None)دریافت امن مقداردر نبود کلید، default را برمی‌گرداند.
keys()نمای کلیدهایک view پویا برمی‌گرداند.
values()نمای مقادیریک view پویا برمی‌گرداند.
items()نمای جفت‌هاجفت‌های (key, value) را ارائه می‌کند.
update(other)ادغام/به‌روزرسانیکلیدهای مشترک با مقدار جدید جایگزین می‌شوند.
setdefault(key, default=None)گرفتن مقدار یا ساخت کلیداگر کلید نباشد آن را با default می‌سازد.
pop(key[, default])حذف کلید و برگرداندن مقداربدون default و با کلید ناموجود، KeyError.
popitem()حذف آخرین جفت درج‌شدهیک tuple شامل (key, value) می‌دهد.
clear()خالی کردن دیکشنریخود دیکشنری را تغییر می‌دهد.
copy()کپی سطحییک دیکشنری جدید با همان ارجاع مقادیر تو در تو.
fromkeys(iterable, value=None)ساخت دیکشنری از کلیدهاهمه کلیدها مقدار اولیه یکسان می‌گیرند.

keys، values و items

user = {"name": "Ali", "age": 22}

print(user.keys())    # dict_keys([...])
print(user.values())  # dict_values([...])
print(user.items())   # dict_items([...])

# می‌توان روی آن‌ها حلقه زد
for key in user.keys():
    print(key)

این‌ها List نیستند؛ viewهای پویا هستند. اگر دیکشنری تغییر کند، view نیز تغییرات را منعکس می‌کند. اگر واقعاً List لازم داری، تبدیل کن:

key_list = list(user.keys())
value_list = list(user.values())
item_list = list(user.items())

update

profile = {"name": "Sara", "age": 20}
profile.update({"age": 21, "city": "Tabriz"})
print(profile)
# {'name': 'Sara', 'age': 21, 'city': 'Tabriz'}

profile.update(country="Iran")

اگر کلیدی در هر دو دیکشنری باشد، مقدار ورودی جدید جای مقدار قبلی را می‌گیرد. update() دیکشنری اصلی را تغییر می‌دهد و دیکشنری جدید برنمی‌گرداند.

setdefault

student = {"name": "Mina"}

result = student.setdefault("grade", 18)
print(result)   # 18
print(student)  # کلید grade اضافه شده

result = student.setdefault("name", "Unknown")
print(result)   # Mina؛ مقدار قبلی تغییر نمی‌کند

تفاوت مهم: get() فقط می‌خواند؛ setdefault() اگر کلید نباشد آن را ایجاد می‌کند.

fromkeys

keys = ["name", "age", "city"]
new_dict = dict.fromkeys(keys, None)
print(new_dict)
# {'name': None, 'age': None, 'city': None}
دام مهم با مقدار mutable: همه کلیدها به همان شیء مشترک اشاره می‌کنند، اگر value یک List باشد.
bad = dict.fromkeys(["a", "b"], [])
bad["a"].append(10)
print(bad)  # {'a': [10], 'b': [10]}  هر دو یک List مشترک دارند!

# روش درست برای List مستقل:
good = {key: [] for key in ["a", "b"]}
good["a"].append(10)
print(good)  # {'a': [10], 'b': []}

کپی سطحی و عمیق

original = {"name": "Ali", "scores": [18, 19]}
shallow = original.copy()

shallow["name"] = "Sara"
shallow["scores"].append(20)

print(original)
# name همچنان Ali است، اما scores شامل 20 شده است.

copy() فقط دیکشنری بیرونی را کپی می‌کند؛ اشیای تو در تو مشترک‌اند. برای کپی مستقل و عمیق:

import copy

deep = copy.deepcopy(original)

۷. الگوهای کاربردی و نکات پیشرفته

الف) شمارش تکرارها با Dictionary

words = ["python", "sql", "python", "linux", "sql", "python"]
counts = {}

for word in words:
    if word in counts:
        counts[word] += 1
    else:
        counts[word] = 1

print(counts)
# {'python': 3, 'sql': 2, 'linux': 1}

نسخه کوتاه‌تر با get():

counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1

ب) گروه‌بندی داده‌ها

records = [
    ("Sara", "Python"),
    ("Ali", "SQL"),
    ("Mina", "Python"),
    ("Reza", "SQL")
]

groups = {}
for name, course in records:
    if course not in groups:
        groups[course] = []
    groups[course].append(name)

print(groups)
# {'Python': ['Sara', 'Mina'], 'SQL': ['Ali', 'Reza']}

ج) حذف تکراری‌های یک List

numbers = [3, 1, 3, 2, 1, 4]
unique = list(set(numbers))
print(unique)
این روش ترتیب اصلی عناصر را تضمین نمی‌کند. برای حذف تکراری‌ها با حفظ ترتیب از این روش استفاده کن:
numbers = [3, 1, 3, 2, 1, 4]
unique_ordered = list(dict.fromkeys(numbers))
print(unique_ordered)  # [3, 1, 2, 4]

د) بررسی اشتراک دو List

registered = ["Ali", "Sara", "Mina"]
paid = ["Sara", "Reza", "Ali"]

both = set(registered) & set(paid)
print(both)  # {'Ali', 'Sara'} (ترتیب مهم نیست)

هـ) Dictionary Comprehension

مانند List Comprehension، اما خروجی یک Dictionary است.

squares = {x: x ** 2 for x in range(1, 6)}
print(squares)
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

even_squares = {x: x ** 2 for x in range(1, 11) if x % 2 == 0}

و) Set Comprehension

remainders = {x % 3 for x in range(10)}
print(remainders)  # {0, 1, 2}

ز) ادغام دیکشنری‌ها

a = {"x": 1, "y": 2}
b = {"y": 99, "z": 3}

merged = a | b             # Python 3.9+
print(merged)              # y از b می‌آید؛ مقدار 99

# روش سازگار با نسخه‌های قدیمی‌تر:
merged2 = {**a, **b}

# یا:
merged3 = a.copy()
merged3.update(b)

ح) عملگر عضویت

person = {"name": "Sara", "age": 20}

print("name" in person)       # True؛ بررسی کلید
print("Sara" in person)       # False؛ مقدار را بررسی نمی‌کند
print("Sara" in person.values())  # True
نکته کلیدی: in روی Dictionary به‌طور پیش‌فرض کلیدها را بررسی می‌کند، نه valueها.

ط) دسترسی به داده‌های تو در تو

company = {
    "name": "Tech Co",
    "employees": [
        {"name": "Sara", "skills": ["Python", "SQL"]},
        {"name": "Ali", "skills": ["Linux", "C"]}
    ]
}

print(company["employees"][0]["skills"][1])  # SQL

ی) حل ساده با Counter

from collections import Counter

words = ["a", "b", "a", "c", "a", "b"]
counter = Counter(words)

print(counter)               # Counter({'a': 3, 'b': 2, 'c': 1})
print(counter.most_common(2)) # [('a', 3), ('b', 2)]

Counter یک ابزار تخصصی مبتنی بر دیکشنری برای شمارش است؛ دانستنش مفید است، اما ابتدا منطق شمارش دستی را کامل یاد بگیر.

۸. مقایسه Set و Dictionary

موضوعSetDictionary

از نظر سرعت چه؟

بررسی عضویت با in در Set و بررسی وجود کلید در Dictionary به‌طور متوسط زمان نزدیک به O(1) دارد. در List بررسی عضویت معمولاً O(n) است. این‌ها پیچیدگی متوسط‌اند، نه تضمین زمان ثابت در همه شرایط.

Set و Dictionary هر دو بر پایه Hash Table پیاده‌سازی شده‌اند؛ به همین علت شرط hashable بودن اعضای Set و کلیدهای Dictionary اهمیت دارد.

۹. اشتباهات رایج و دام‌های مهم

  1. اشتباه گرفتن Set خالی و Dictionary خالی: {} دیکشنری است؛ set() مجموعه خالی است.
  2. استفاده از اندیس برای Set: Set اندیس ندارد.
  3. عضو یا کلید mutable: List و Dictionary نمی‌توانند عضو Set یا کلید Dictionary باشند.
  4. فراموش کردن تفاوت remove و discard: اولی در نبود عضو خطا می‌دهد؛ دومی نه.
  5. انتظار خروجی از متدهای تغییردهنده: متدهایی مثل add، clear و update را به‌عنوان مقدار بازگشتی استفاده نکن.
  6. فکر کردن in در Dictionary مقدار را می‌سنجد: فقط کلید را می‌سنجد.
  7. فرض ترتیب در Set: روی ترتیب اعضا حساب نکن.
  8. کپی سطحی: کپی کردن دیکشنری، Listهای تو در تو را مستقل نمی‌کند.
  9. استفاده نادرست از fromkeys با List: ممکن است تمام کلیدها به یک List مشترک اشاره کنند.
  10. اشتباه گرفتن pop و popitem: در Dictionary، pop(key) با کلید کار می‌کند؛ popitem() آخرین جفت درج‌شده را حذف می‌کند. در Set، pop() یک عضو دلخواه را حذف می‌کند.

۱۰. تمرین‌ها

پیشنهاد: ابتدا بدون دیدن پاسخ فکر کن و کد را خودت اجرا کن. هدف فقط حفظ کردن متدها نیست؛ باید تشخیص بدهی کدام ساختار برای مسئله مناسب‌تر است.

تمرین ۱ — حذف تکراری‌ها

از List زیر یک مجموعه از اعداد یکتا بساز و تعداد اعضای یکتا را چاپ کن.

numbers = [4, 2, 4, 7, 2, 9, 7, 1]

تمرین ۲ — تحلیل دو گروه

دو Set از دانشجویانی که در دو کارگاه ثبت‌نام کرده‌اند بساز. موارد زیر را چاپ کن: افراد حاضر در هر دو کارگاه، فقط کارگاه اول، و افرادی که فقط در یکی از دو کارگاه هستند.

تمرین ۳ — شمارش کلمات

با یک Dictionary تعداد تکرار هر کلمه را در لیست زیر حساب کن. سپس کلمه پرتکرار را پیدا کن.

words = ["sql", "python", "sql", "linux", "python", "sql"]

تمرین ۴ — موجودی فروشگاه

دیکشنری موجودی محصولات را بساز. سپس تعداد محصول mouse را ۵ واحد افزایش بده؛ محصول keyboard را حذف کن؛ اگر monitor وجود نداشت مقدار پیش‌فرض صفر نشان بده.

تمرین ۵ — گروه‌بندی نمرات

از لیستی شامل زوج‌های (نام دانشجو، نام درس)، دیکشنری‌ای بساز که کلید آن نام درس و مقدار آن لیست دانشجویان همان درس باشد.

تمرین ۶ — چالش ترکیبی

اطلاعات سفارش‌ها به شکل زیر است. یک دیکشنری بساز که برای هر مشتری مجموع مبلغ خرید را نگه دارد. سپس Set مشتریانی را بساز که مجموع خریدشان حداقل ۲۰۰۰ است.

orders = [
    ("O1", "Sara", 1200),
    ("O2", "Ali", 800),
    ("O3", "Sara", 900),
    ("O4", "Mina", 2500),
    ("O5", "Ali", 1400)
]

پاسخ تمرین ۳ 
words = ["sql", "python", "sql", "linux", "python", "sql"]
counts = {}

for word in words:
    counts[word] = counts.get(word, 0) + 1

most_common_word = max(counts, key=counts.get)
print(counts)
print(most_common_word, counts[most_common_word])

records = [
    ("Sara", "Python"),
    ("Ali", "SQL"),
    ("Mina", "Python"),
    ("Reza", "SQL")
]

groups = {}
for name, course in records:
    groups.setdefault(course, []).append(name)

print(groups)
پاسخ تمرین ۶ 
orders = [
    ("O1", "Sara", 1200),
    ("O2", "Ali", 800),
    ("O3", "Sara", 900),
    ("O4", "Mina", 2500),
    ("O5", "Ali", 1400)
]

totals = {}
for order_id, customer, amount in orders:
    totals[customer] = totals.get(customer, 0) + amount

qualified = {
    customer
    for customer, total in totals.items()
    if total >= 2000
}

print(totals)
print(qualified)

خروجی مجموع‌ها: Sara برابر 2100، Ali برابر 2200 و Mina برابر 2500 است؛ پس هر سه مشتری در Set نهایی قرار می‌گیرند.

جمع‌بندی نهایی

  • برای نگهداری اعضای یکتا و عملیات اجتماع/اشتراک/تفاضل، از Set استفاده کن.
  • برای نگاشت یک شناسه یا کلید به یک مقدار، از Dictionary استفاده کن.
  • در Set، متدهای add، update، remove و discard را خوب بلد باش.
  • در Dictionary، تفاوت []، get و setdefault بسیار مهم است.
  • برای پیمایش Dictionary، keys()، values() و مخصوصاً items() را بشناس.
  • مفهوم hashable بودن، کپی سطحی و mutable بودن را درک کن؛ این‌ها پایه فهم رفتار این دو ساختارند.
معیار تسلط: اگر بتوانی تمرین‌های ۳ تا ۶ را بدون نگاه کردن به جزوه حل کنی و توضیح بدهی چرا از Set یا Dictionary استفاده کرده‌ای، مفاهیم اصلی را یاد گرفته‌ای.
