PART 1 — PYTHON DATA TYPES

Python has several built-in data types. Each type is designed to store a specific kind of data.

1. Numeric Types

Python has three main numeric types:

1.1 Integer (int)

Stores whole numbers without decimal points.

age = 20
temperature = -5
population = 1000000

Useful functions:

Function Description Example
int()Converts a value to integerint("25") → 25
abs()Returns absolute valueabs(-10) → 10
pow()Calculates powerpow(2, 3) → 8
round()Rounds a numberround(3.7) → 4

1.2 Float (float)

Stores numbers with decimal points.

price = 19.99
height = 1.75

Useful functions:

float("12.5")      # 12.5
round(3.14159, 2)  # 3.14
abs(-4.5)          # 4.5

1.3 Complex (complex)

Stores complex numbers with real and imaginary parts.

x = 3 + 4j

print(x.real)  # 3.0
print(x.imag)  # 4.0

Useful function:

complex(2, 3)  # (2+3j)

message = 'Hello World'

String Formatting

Three common approaches:

1. f-strings (Recommended)

2. format()

3. Boolean (bool)

Boolean values represent logical states.

There are only two Boolean values:

True
False

Examples:

Useful functions:

4. List (list)

A list stores multiple values in an ordered and mutable collection.

Lists allow duplicate values and different data types.

numbers = [10, 20, 30, 40]
mixed = [10, "Python", True, 3.5]

Accessing Elements

numbers = [10, 20, 30, 40]

numbers[0]    # 10
numbers[-1]   # 40
numbers[1:3]  # [20, 30]
numbers[:2]   # [10, 20]
numbers[2:]   # [30, 40]

5. Tuple (tuple)

A tuple is an ordered and immutable collection.

Unlike lists, tuples cannot be modified after creation.

coordinates = (10, 20)
colors = ("red", "green", "blue")

Accessing Elements

colors[0]    # red
colors[-1]   # blue
colors[0:2]  # ('red', 'green')

Tuple Methods

Tuples have only two main methods:

MethodDescription

Example:

numbers = (1, 2, 2, 3)

numbers.count(2)  # 2
numbers.index(3)  # 3

Important Concept: Tuple Packing and Unpacking

person = ("Sama", 20, "Computer Engineering")

print(name)
print(age)

A tuple with one element needs a comma:

6. Set (set)

A set is an unordered collection of unique elements.

Sets do not allow duplicate values.

numbers = {1, 2, 3, 3, 4}

print(numbers)
# {1, 2, 3, 4}

Sets are mutable, but their elements must be hashable.

Important Set Methods

MethodDescription

symmetric_difference()Returns elements that are not common

issuperset()Checks whether a set is a superset

Examples:

# {1, 2, 3, 4, 5}

print(a.intersection(b))
# {3}

print(a.difference(b))
# {1, 2}

print(a.symmetric_difference(b))
# {1, 2, 4, 5}

Set Operators

a - b  # Difference

7. Dictionary (dict)

A dictionary stores data as key-value pairs.

Dictionaries are mutable and preserve insertion order.

student = {
    "name": "Sama",
    "age": 20,
    "major": "Computer Engineering"
}

Accessing Values

student["name"]

student.get("age")

student.get("grade", 0)

Important Difference

  • student["grade"] raises KeyError if the key does not exist.
  • student.get("grade") returns None by default.

Important Dictionary Methods

MethodDescription

Examples:

student = {
    "name": "Sama",
    "age": 20
}

student["grade"] = 18

student.update({"age": 21})

print(student.keys())
print(student.values())
print(student.items())

Dictionary Iteration

for key in student:
    print(key)

for value in student.values():
    print(value)

for key, value in student.items():
    print(key, value)

8. NoneType

None represents the absence of a value.

result = None

print(result is None)  # True

Important Points

  • None is not equal to zero.
  • None is not an empty string.
  • None is not False.
  • Use is None to check for None.

Example:

def get_user():
    return None

result = get_user()

if result is None:
    print("No user found")

PART 4 — IMPORTANT CONCEPTS

1. Mutable vs Immutable

Th is is one of the most important concepts in Python.

Mutable Objects

Their contents can be changed after creation.

  • list
  • dict
  • set

Example:

numbers = [1, 2, 3]

numbers.append(4)

print(numbers)
# [1, 2, 3, 4]

Immutable Objects

Their contents cannot be changed after creation.

  • int
  • float
  • bool
  • str
  • tuple
  • frozenset
  • bytes

Example:

name = "Python"

name.upper()

print(name)
# Python

The upper() method returns a new string. It does not modify the original.

2. Shallow Copy vs Reference

Consider:

a = [1, 2, 3]
b = a

b.append(4)

print(a)
# [1, 2, 3, 4]

Both variables refer to the same list.

Now consider:

a = [1, 2, 3]
b = a.copy()

b.append(4)

print(a)
# [1, 2, 3]

print(b)
# [1, 2, 3, 4]

A shallow copy creates a new outer object, but nested mutable objects can still be shared.

For deeply nested structures, Python provides copy.deepcopy().

3. Type Conversion

Python allows conversion between many data types.

int("25")          # 25
float("3.14")      # 3.14
str(100)           # "100"
list("Python")     # ['P', 'y', 't', 'h', 'o', 'n']
tuple([1, 2, 3])   # (1, 2, 3)
set([1, 1, 2])     # {1, 2}

Important:

int("hello")

Raises a ValueError.

Not every value can be converted into every type.
